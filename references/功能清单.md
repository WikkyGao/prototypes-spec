# 功能清单（xlsx 格式）生成规范

本文件指导如何从原型解析数据生成结构化功能清单 Excel 文件。当用户要求生成"功能清单"且需要 xlsx 格式时读取本文件。

## 输出文件

- 文件名：`功能清单.xlsx`
- 位置：原型目录下 `_output/` 或用户指定位置
- 格式：Excel `.xlsx`，使用 `openpyxl` 库生成

## 工作表结构

### 主表「功能清单」

按模块（页面）分组组织，每组首行为模块标题行（合并单元格 + 荈色填充），后续为该模块的功能条目。

**列定义**（8 列，固定顺序）：

| 列 | 字段 | 宽度 | 说明 |
|----|------|------|------|
| A | 功能编号 | 12 | 格式 `F-XXX`，三位序号，全局递增 |
| B | 模块 | 18 | 所属功能模块名（对应原型页面名） |
| C | 功能名称 | 22 | 简洁动宾结构（如"查看实例列表"） |
| D | 功能描述 | 40 | 一句话描述功能意图与输入输出 |
| E | 优先级 | 8 | P0（核心）/ P1（重要）/ P2（一般）/ P3（边界） |
| F | 所属页面 | 18 | 原型页面名（来源追溯） |
| G | 关联功能 | 18 | 该功能依赖或被依赖的其他功能编号（逗号分隔） |
| H | 备注 | 30 | 业务规则/约束/来源备注说明 |

**示例行**：

| A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|
| F-001 | 实例管理 | 查看实例列表 | 展示所有服务实例，含名称/版本/状态/IP | P0 | 实例管理 | F-002 | 树形导航筛选可见 |
| F-002 | 实例管理 | 树形导航筛选 | 按节点类型筛选实例列表 | P1 | 实例管理 | F-001 | - |

### 副表「说明」

第二张工作表，记录文档元信息：

| 字段 | 内容 |
|------|------|
| 项目名称 | 原型项目名 |
| 生成日期 | YYYY-MM-DD |
| 数据来源 | 原型工具类型（Axure/墨刀/MasterGo/蓝湖） |
| 功能总数 | N |
| 备注 | 「备注说明」字段来自原型便签/矩形备注，已合并入功能描述与备注列 |

## 功能推断规则

从原型页面内容推断功能时遵循以下规则：

1. **页面即模块**：每个原型页面对应一个功能模块，页面名作为模块名
2. **控件类型映射功能**：

| 控件类型 | 推断功能 |
|---------|---------|
| 表格 | 查看 XX 列表 |
| 输入框 + 按钮 | 新增/编辑 XX |
| 树形导航 | 按 XX 筛选/导航 |
| 下拉列表 | 选择 XX |
| 查询按钮 + 输入框 | 按条件查询 XX |
| 确定按钮 | 提交 XX |
| 返回按钮 | 返回上一级 |
| 链接/onClick | 跳转至 XX |

3. **页面标题推断主功能**：页面 `<title>` 或首行大文本通常暗示页面主功能
4. **按钮文字推断操作功能**：含"确定/提交/保存/发布"等动词的按钮文字直接作为功能名
5. **业务流程页特殊处理**：含"流程"字样的页面，将其拆分为多个有序步骤功能

## 优先级评定

| 优先级 | 判定条件 |
|--------|---------|
| P0 | 页面主功能、表单提交、列表加载、认证相关 |
| P1 | 筛选/查询/导航/跳转、详情查看 |
| P2 | 重置/返回/展开折叠/排序 |
| P3 | 边界场景、异常处理、非核心交互 |

## 便签/备注说明的纳入

原型解析数据中每页的 `notes` 字段（便签/矩形内备注说明）应：

- **补为独立功能条目**：若备注说明的是一项可操作的业务规则（如"Access Token 有效期 24 小时"→ 功能"Token 有效期管理"）
- **合并入关联功能的备注列**：约束类说明（如"跨 VLAN 调用验证不通过"）填入关联功能的 H 列
- **补入功能描述**：业务流程类备注扩展现有功能的描述
- 在副表「说明」的「备注」字段标注已纳入

## 生成脚本

**对应脚本**：`scripts/generate_feature_list.py`（可独立执行）。

**用法**：
```bash
# 先用 parse_axure.py 拿到解析 JSON
python3 scripts/parse_axure.py <原型目录> --json > prototype.json

# 再跑生成脚本
python3 scripts/generate_feature_list.py prototype.json [输出路径]
```

脚本会按本文件的列定义/分组/便签纳入规则生成 `功能清单.xlsx`。若需调整推断逻辑，直接编辑该脚本对应函数。

## 使用要点

1. **按页面分组**：功能按所属页面组织，合并单元格做模块标题
2. **全局编号**：`F-XXX` 全局递增，便于跨模块引用
3. **关联功能列**：标注功能依赖关系，便于开发排期
4. **不要过度推断**：原型中未体现的功能不编造，标注「（待补充）」
5. **备注说明优先**：`notes` 字段内容补入功能条目或备注列
6. **冻结首行**：`ws.freeze_panes = 'A2'`，长列表可滚动
7. **优先级保守**：无法确定时用 P1，避免误判 P0
