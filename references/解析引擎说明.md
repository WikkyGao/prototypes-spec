# 解析引擎说明

`scripts/parse_axure.py` 的工具识别机制、各工具解析深度对比与 Axure 数据键说明。调试解析降级行为、扩展新原型工具支持时读取本文件。

## 工具识别（detect_tool_type）

脚本按「Axure → 墨刀 → MasterGo → 蓝湖 → 未知」顺序识别工具类型，判定特征同 SKILL.md 工作流步骤 1 的表格，第一个匹配成功即返回。

**降级原则**：任一工具缺数据源时退化为通用 HTML 扫描，输出中标注"降级版本"。

## 各工具解析深度对比

| 工具       | 数据源                              | 页面树     | 文本          | 控件类型           | 交互事件      | 便签/备注               |
| -------- | -------------------------------- | ------- | ----------- | -------------- | --------- | ------------------- |
| Axure    | `document.js` + HTML + `data.js` | ✓ 树形    | ✓ span      | ✓ friendlyType | ✓ onClick | ✓ `_ann` div + 矩形备注 |
| 墨刀       | HTML + `index.html` 链接           | ✗ 扁平    | ✓ span      | ✓ 注释           | ✗         | ✓ 矩形备注              |
| MasterGo | `PAGED_FRAMES` JS                | ✗ 画板列表  | ✗           | ✗              | ✗         | ✗                   |
| 蓝湖       | `.schema.json` 图层树               | ✗ 每画板独立 | ✓ lanhutext | ✓ 图层类型         | ✗         | ✗                   |
| 未知       | HTML 扫描                          | ✗ 扁平    | ✓ span      | ✓ 注释           | ✗         | ✓ 矩形备注              |

## Axure 数据键

- `document.js` 用 `"pageName"`/`"url"`/`"children"` 标识页面层级
- 每页 `data.js` 用 `friendlyType`/`label`/`interactionMap`/`style` 描述控件
- HTML 中 `<span>` 装载可见文本、`<!-- Unnamed (类型) -->` 标识控件、`table_cell` 类标识表格、`<img>` 引用 `images/`
