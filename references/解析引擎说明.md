# 解析引擎说明

`scripts/parse_axure.py` 的工具识别机制、各工具解析深度对比与 Axure 数据键说明。调试解析降级行为、扩展新原型工具支持时读取本文件。

## 工具识别（detect_tool_type）

脚本按「Axure → 墨刀 → MasterGo → 蓝湖 → 未知」顺序识别工具类型，判定特征同 SKILL.md 工作流步骤 1 的表格，第一个匹配成功即返回。

**降级原则**：任一工具缺数据源时退化为通用 HTML 扫描，输出中标注"降级版本"。

## Axure data.js 双格式解析（parse_page_data_js）

data.js 有两种导出格式，脚本自动选择解析路径（返回值含 `extractor` 字段标注实际使用的路径）：

| 格式 | 特征 | 解析路径 |
|------|------|---------|
| RP10 压缩格式（Axure RP 9+/10） | `$axure.loadCurrentPage((function(){...})())`，键值被替换为符号变量（`var b="url", c="实例管理.html"...`） | 内置求值器（`extractor: rp10_eval`） |
| 旧版明文格式（Axure 8/9） | 含 `"label","xxx"`、`"friendlyType","按钮"` 明文键值对 | 正则提取（`extractor: legacy_regex`） |

**RP10 求值器**：先收集文件尾部的符号表（3400+ 个 `var x="字面量"` 声明），再对 `_creator` 中 `return _(b,c,...)` 表达式做递归下降求值（`_()` 组合器按 JS 语义建字典：奇数参数丢弃末尾键、对象键 coerce 为字符串）。求值成功后从对象图提取控件（含 `style.location` 坐标）与交互（`interactionMap` → 事件/动作/跳转目标）。求值失败自动退回正则路径，不会比修复前更差。

**注意**：与旧格式不同，RP10 格式的每页 `data.js` 不含明文控件名，任何直接 grep `friendlyType` 的正则都提取不到数据——必须走求值器。

## 筛选区域坐标核实（detect_filter_area）

管理后台的筛选字段识别采用**三重证据**（需完整导出包的 `files/<页面>/styles.css` 提供控件坐标）：

1. **行带**：候选文本位于查询/重置按钮同一行带（±50px，按钮左侧）
2. **对齐**：与某输入控件（`<input>/<select>` 的 `uNNN_input` → `uNNN`）水平对齐 |Δx|≤30、垂直对齐 |Δy|≤25，且为单行小文本（h≤24px）——Axure 的筛选标签是叠加在 text_field 内左缘的文本层
3. **非数据值**：`_is_data_value` 排除 IP/纯数字/页面重复值

三重证据通过的字段 `filter_area.verified=true`；无坐标（单文件模式/缺 CSS）时退化为关键词匹配（`verified=false`），note 标注未经核实。绝对定位的动态面板各状态互相堆叠，仅靠行带位置会把表格数据/树节点/按钮文字全部误收——**不要放宽为仅位置判定**。树容器内的文本（`selectiongroup` 含 `_tree_group`）一律排除。

## 各工具解析深度对比

| 工具       | 数据源                              | 页面树     | 文本          | 控件类型           | 交互事件      | 便签/备注               |
| -------- | -------------------------------- | ------- | ----------- | -------------- | --------- | ------------------- |
| Axure    | `document.js` + HTML + `data.js` | ✓ 树形    | ✓ span      | ✓ friendlyType | ✓ onClick | ✓ `_ann` div + 矩形备注 |
| 墨刀       | HTML + `index.html` 链接           | ✗ 扁平    | ✓ span      | ✓ 注释           | ✗         | ✓ 矩形备注              |
| MasterGo | `PAGED_FRAMES` JS                | ✗ 画板列表  | ✗           | ✗              | ✗         | ✗                   |
| 蓝湖       | `.schema.json` 图层树               | ✗ 每画板独立 | ✓ lanhutext | ✓ 图层类型         | ✗         | ✗                   |
| 未知       | HTML 扫描                          | ✗ 扁平    | ✓ span      | ✓ 注释           | ✗         | ✓ 矩形备注              |

## Axure 数据键

- `document.js` 用 `"pageName"`/`"url"`/`"children"` 标识页面层级
- 每页 `data.js` 用 `friendlyType`/`label`/`interactionMap`/`style` 描述控件
- HTML 中 `<span>` 装载可见文本、`<!-- Unnamed (类型) -->` 标识控件、`table_cell` 类标识表格、`<img>` 引用 `images/`
